# Security policy

Spoolmap processes community-created 3MF archives and inventory exports, so malformed-input reports are especially valuable. Parsing, matching, inventory handling, and export happen in the browser. The hosted app does not upload projects or spool inventory.

Please use GitHub's private vulnerability reporting for issues that could expose files, execute script, exhaust resources, or bypass archive bounds. If private reporting is unavailable, open an issue without exploit details and ask for a private contact channel.

Include the affected version, browser and operating system, a minimal reproducer when it is safe to share, and the impact you observed. Do not include private print projects or spool inventories.

Security fixes are supported on the latest code on `main`.
